## Steps

### Step 1: Overrides

Re-run `pnpm audit --prod` to get fresh advisory data (it shifts). Add to
`package.json` the minimum override set (replace the observed operators with
whatever the current output requires — the executor must re-verify):

```json
"pnpm": {
  "overrides": {
    "form-data": ">=2.5.6",
    "undici": ">=6.29.1",
    "zod": ">=4.6.6",
    "body-parser": ">=2.4.0"
  }
}
```

Then `pnpm install` (writes `pnpm-lock.yaml`) and re-run
`pnpm audit --prod`. Careful: bump transitive ranges broadly enough to keep
`@modelcontextprotocol/sdk` and `node-telegram-bot-api` working — the runtime
tests must confirm.

**Verify**: `pnpm audit --prod` → re-run; if any critical/high remain that
affects runtime code, report the specific package (do not force-pin by
deprecated majors).

### Step 2: CHANGELOG migration table

Append a new section at the top of `CHANGELOG.md`, `## [0.13.0] (unreleased - security)`,
with:

- The operator-approved quick migration table (exact approved content):
  - A2A: upgrade all bridges in the mesh to ≥0.13.0. No config change; legacy
    unsigned peers accepted with warnings, `a2a.secure: true` hardens both sides.
  - HTTP: non-loopback bind without `http.auth.token` → **bridge does not start**
    (add a token or bind loopback); commands over `/prompt` now need
    `http.commands: true`; internal `callbackUrl` hosts need
    `http.callbackAllow: ["host"]`.
  - Agent-cron: agent-created jobs with `/`-prompts no longer run bridge
    commands (recreate as operator `/cron add` if intended).
  - `/a2a/confirm` no longer auto-approves; run `/a2a approve` to complete both sides.
  - Registry `announce` requires a signed peer session or loopback origin to
    change `cardUrl`/`card`.
- "Breaking" heading marking HTTP + A2A semantics.
- Deps note: transitive pins with the advisories' CVE/GHSA ids as
  `GHSA-6pq8-jhm2-2vcw` form (pull each id from the audit output — never
  invent ids).

**Verify**: `pnpm lint` → exit 0; read the file and confirm the section renders
(markdown lint is not in scope; visual check only).
